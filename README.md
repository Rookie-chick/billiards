# 🎱 8 球台球 · 腾讯桌球风格

纯前端的网页台球游戏：**HTML5 Canvas 2D + 原生 JavaScript，零依赖、零构建**。
把仓库拉下来，双击 `index.html` 就能开打，不需要装任何东西。

人机对战，三档 AI 难度，标准 8 球规则。

---

## 快速开始

```bash
# 方式一：直接双击 index.html（推荐）
# 方式二：起个本地服务（音效需要用户交互后才能播，某些浏览器下更稳）
python -m http.server 8000
# 然后打开 http://localhost:8000
```

## 操作

| 操作 | 说明 |
| --- | --- |
| 移动鼠标 | 瞄准（球杆实时跟随） |
| 按住左键 | 蓄力，松开出杆 |
| 空格 | 同样可以蓄力，松开出杆 |
| **滚轮** | 瞄准微调，每格 **0.3°** |
| **Shift + 滚轮** | 精调，每格 **0.05°** |
| **R** | 微调归零 |
| Esc | 取消蓄力 |
| 拖红点 | 加塞（上下=高低杆，左右=侧塞），双击回中 |
| 底部卡片 | 切换球杆 |
| 右上按钮 | 音效开关 / 辅助线开关 / AI 难度 / 重新开局 |

> 袋口边那几个像素怎么啃？距袋 400px 时，滚一格 ≈ 2.1px 落点位移，Shift 精调 ≈ 0.35px。
> 微调量是**叠加在鼠标方向上的偏移量**，鼠标怎么动都不会丢，出杆或按 R 才清零。

## 球杆分档

三根杆，力度和"能预判多远"都不一样：

| 球杆 | 力度 | 辅助线 |
| --- | --- | --- |
| 练习木杆 ★☆☆ | ×1.0 | 目标球去向箭头 55px |
| 进阶碳杆 ★★☆ | ×1.2 | 85px 箭头 + 撞库反弹预判 + 白球分离箭头 |
| 大师金杆 ★★★ | ×1.42 | 120px 箭头 + **两层撞库反弹** + 分离线带反弹 |

## 辅助线怎么读

- **细密白线**：白球出杆方向，会撞库反射
- **半透明鬼影球**：白球理想撞击位置（ghost ball）
- **金色箭头**：目标球被撞后的去向，杆越好箭头越长
- **蓝色箭头**：白球撞完后的分离方向（切线方向）
- **袋口金圈脉动**：这一杆预判能进袋，圈在哪个袋就进哪个袋
- 瞄准线**变红**：白球会直接摔袋，别这么打

## 规则实现

标准 8 球：开球 → 开放球台 → 首个合法落袋定全色/花色 → 清完本组 → 合法打进黑八获胜。

犯规（对手获得自由球，可把白球摆到台面任意合法位置）：

- 白球落袋
- 空杆（没碰到任何球）
- 首先碰到的不是自己的球
- 击球后无球进袋且无球碰库

几个特意处理的边界：

- **开球打进黑八不判负**，重新开局（直接判负太苛刻）
- 没清完本组就打进黑八 → 判负
- 最后一颗球和黑八同杆落下 → 仍判负（按**击球前**的台面状态判定）
- 打进自己最后一颗球**不会**被误判成"首先碰到的不是自己的球"

## 技术要点

物理和渲染都是手写的，没有用任何引擎：

- **碰撞**：固定步长 + 子步连续碰撞检测（CCD），满力开球也不会穿球穿袋
- **摩擦**：库仑摩擦（恒定减速度）为主 + 微量指数阻力，收尾干脆不"爬行"
- **杆法**：高杆跟进 / 低杆缩回 / 侧塞撞库偏移；侧塞**不传给目标球**（真实碰撞传递的是速度不是角动量，传了会让目标球莫名拐弯）
- **滚动姿态**：球会真的滚——条纹带和号码随滚动做球面经度移动，转到背面会压扁消失再从另一侧转回来，白球用标记点显示滚动
- **打击感**：高速拖影、投影拉伸、落袋缩放旋转下沉、瞄准虚线流动
- **瞄准手感**：鼠标方向做低通平滑（远处跟手、近处滤抖），**没有任何死区**，每个方向都选得到
- **AI**：ghost ball 找袋 + 切角评估 + 路径清障 + 安全球，误差模型按像素归一化，三档难度
- **音效**：WebAudio 实时合成，仓库里没有任何音频文件
- **可测试**：Node 无头冒烟测试覆盖摆球、行程标定、杆法、规则、AI 自我对局

## 目录结构

```
billiards/
├── index.html          页面骨架
├── css/style.css       界面样式
└── js/
    ├── config.js       常量（台面尺寸、物理参数、球杆分档）
    ├── audio.js        WebAudio 实时音效
    ├── physics.js      球体运动、碰撞、库边、落袋
    ├── aim.js          瞄准预测（虚拟球、反弹、入袋预判）
    ├── render.js       Canvas 渲染（球滚动、辅助线、特效）
    ├── rules.js        8 球规则判定
    ├── ai.js           AI 出杆决策
    └── game.js         主循环与交互
```

改动物理手感基本只需动 `js/config.js` 里的常量。
